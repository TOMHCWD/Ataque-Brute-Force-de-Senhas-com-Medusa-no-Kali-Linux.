# Preparação do Kali Linux

* **Download:** Baixe a imagem ISO do Kali Linux no link [https://www.kali.org/get-kali/#kali-platforms](https://www.kali.org/get-kali/#kali-platforms)
* **Criação da VM:**
  * **Sistema Operacional:** Kali Linux (Debian 64-bit).
  * **Memória:** 4096 MB (mínimo).
  * **Processador:** 1 vCPUs.
  * **Disco Virtual:** 20 GB (Dinâmico).
* **Instalação:**
  * Selecione a instalação gráfica (Graphical Install).
  * Configuração de rede: Defina o IP estático `192.168.0.10` na interface `eth0` (ou `enp0s3` dependendo da versão).
  * Usuário padrão: `kali` / Senha: `kali` (padrão de fábrica).
